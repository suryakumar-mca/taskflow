# TaskFlow Website

## Overview

TaskFlow is a lightweight task management application. An user can register and create an account for them. Using that they can login and create tasks. Once a task is created, the user can do the following 
	1. Mark the task as completed
	2. Edit the tasks
	3. If wrongly marked as completed, they can edit the completion status to pending again

## Functional Requirements

### Authentication

- User can register
- User can login
- User can logout
- User should only access their own tasks

### Tasks

- Create task
- Update pending task as completer or vice versa
- Delete task
- View all tasks

## Non Functional Requirements

- Secure
- Responsive
- RESTful API
- Password hashing
- JWT authentication

## Out of Scope

- Password reset
- Account deletion
- Task priority
- Categories
